# Contributing

Thanks for helping improve VIN Detective AI.

1. Open an issue describing the bug, evidence gap, or feature request.
2. Fork the repo and work in a new branch.
3. Submit a pull request referencing the issue and explaining how it was tested.
4. For a VIN-specific finding, provide source URLs and exact provenance; redact private information.
5. Do not add images, API tokens, paywalled content, or scraped databases without appropriate rights.

Research quality rules: never fabricate accident history, auction records, mileage, photos or asking prices. Always distinguish absence of evidence from evidence of a clean record.
